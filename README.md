## 📌 Project Overview

**Task Manager App** is a Flutter-based mobile application designed to help users manage daily tasks efficiently. Built using **GetX** for state management and routing, this app provides seamless integration with APIs for real-time data operations.

### 🛠️ Key Features:
- 🔐 User Authentication (Sign Up, Login, Logout)
- 🧑‍💼 Profile Management (Update Profile Info)
- ✅ Task CRUD Operations (Create, Read, Update, Delete)
- 🔄 Dynamic Task Loading from REST API
- 🎯 Intuitive and Responsive UI

This project demonstrates how to structure a real-world app using GetX, API calls, and custom widgets while maintaining clean and scalable architecture.
