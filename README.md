# 📋 Task Manager App

A Flutter Task Management App using GetX with API integration for full-stack functionality.

## 🚀 Features

- 🔐 Sign Up / Login / Logout (User Authentication)
- 🧑 Update Profile
- 📋 Task Management with API (Create, Read, Update, Delete)
- ⚡ Built with Flutter & GetX
- ☁️ Real-time task loading from REST API

---

## 🧠 Tech Stack

- **Flutter**
- **GetX** (State Management & Routing)
- **REST API**
- **Dart**
